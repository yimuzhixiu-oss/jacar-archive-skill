# 目錄.md 模板

由详情页字段按固定顺序生成，一段一个字段，字段名与值之间空一行。

```
件名標題

１ 〔大正６年１２月１７日〕

レファレンスコード

B03051171600

所蔵館における請求番号

1.6.3.24-11_001 （所蔵館：外務省外交史料館）

言語

日本語

資料作成年月日

大正０６年１２月１７日～大正０６年１２月１７日

規模

6

組織歴/履歴

外務省

内容

<详情页「内容」字段全文，单行>

URIをコピー

https://www.jacar.archives.go.jp/das/meta/B03051171600

引用例をコピー

「１ 〔大正６年１２月１７日〕」JACAR(アジア歴史資料センター)Ref.B03051171600、露国革命一件／帝国ノ態度 第一巻(1.6.3.24-11_001)(外務省外交史料館)
```

## 规则

1. 字段顺序固定：件名標題 → レファレンスコード → 所蔵館における請求番号 → 言語 → 作成者名称 → 資料作成年月日 → 規模 → 組織歴/履歴 → 内容 → URI → 引用例
2. **缺哪项就跳过哪项**，不留空行占位（表紙/目次类常缺作成者和日期）
3. 「内容」必须完整照抄，不做摘要、不截断。这是用户查条目内容的主要凭据
4. 「引用例」直接用站点生成的那一句，不要自己拼，避免括号与空格出错
5. 文件编码 UTF-8，无 BOM，末尾一个换行

## 与旧库的差异

旧库有三种文件名：`目錄.md`(93) / `目录.md`(6) / `目錄詳細情報.md`(8)。

- 默认写 `目錄.md`（主流）
- `--meta-name` 可改
- `目錄詳細情報.md` 的差异：多一个 `階層` 字段，且把「引用例をコピー」写成「論文などへの引用例」。需要时用 `--meta-name 目錄詳細情報.md` 并在代码里走 detailed 分支
