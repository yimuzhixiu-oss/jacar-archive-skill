# 命名规则

## 总原则

**序号由原文决定，脚本不做事后格式化。** 不补零、不去零、不截断、不改位数。
仅把序号段的全角数字转半角（便于排序），正文一个字符不动。

## 主序号

从标题开头取 1–2 位数字，后跟点号（`.` 或 `．`）或空格：

| 原文 | 结果 | 说明 |
| --- | --- | --- |
| `１．本邦／１ 大正７年…` | `1.1本邦／１ 大正７年…` | 主号 1，追加 ／1 |
| `１４ 大正９年５月１３日…` | `14.大正９年５月１３日…` | 序号后空格去掉 |
| `２.１９１７年〔大正６年〕…` | `2.１９１７年〔大正６年〕…` | 1917 是年份，不是序号 |
| `1.6.1西比利亜…` | `1.6.1西比利亜…` | 已是三段，不再追加 |

**关键负向断言**：`(?![0-9０-９年])`。没有它 `2.１９１７年` 会被切成 `2.19`，这是唯一会静默生成错名的地方。

## 子项追加

正文里每个 `／N` 追加为一段小数位，取哪个数字有优先级：

1. **「／」前紧邻的数字优先**：`３ 〔日期〕 ２／标题` → `3.2`
2. 否则取「／」后的数字：`１．本邦／１ 大正…` → `1.1`
3. 「／」两侧都没数字：记 `0`，如 `１．独国／内容要綱` → `1.0`

**启发式**：主序号已含两段以上时不再追加。否则 `1.6.1…／６）…／１` 会变成 `1.6.1.6.1`。
这条是经验判断，不是硬规则，可用 `--numbering raw` 整个关掉。

## 无序号条目

| 标题 | 结果 |
| --- | --- |
| `表紙` | `0.表紙` |
| `目次` | `0.1目次` |
| 其他无序号（如 `〔中表紙〕／…`） | 按出现顺序 `0.2`、`0.3`… |

## 尾号并入（`tail_rule`）

仅在 profile 里按册开启。适用于「１ 露国政変概要 １」这类子项号在正文末尾的标题：

```
１ 露国政変概要 １  →  1.1露国政変概要 1
３ 〔日期〕 １        →  3.1〔日期〕 1
```

不开启时结果是 `1.露国政変概要 １`（保序但不分项）。

## 簿冊标题 → 目录

按全角 `／` 切分；若某段以「第X巻 / 第X卷」结尾，该部分再单独成层：

```
露国革命一件／帝国ノ態度  第一巻
  → 露国革命一件 / 帝国ノ態度 / 第一巻
```

- 若首段与 `--base` 末级目录「异体字归一后相同」，丢弃首段（base 已是件名级）
- 逐段向下时，若已有「归一后同名」的目录（`第二巻` vs `第二卷`），**进入旧目录不新建**
- 落盘一律用 JACAR 原文，不做繁简转换

异体字归一只用于比较：国/國、巻/卷、録/錄、参/參、戦/戰、総/總、会/會、体/體、学/學、実/實、発/發、関/關、広/廣、欧/歐、亜/亞…

## 字符处理

| 情况 | 处理 |
| --- | --- |
| 半角 `/` | → 全角 `／`（史料库中半角 `/` 数量应为 0） |
| 连续空格 | 折叠为 1 个 |
| 序号后空格 | 去掉 |
| 首尾空格、U+3000、尾部 `.` | 去掉 |
| 全角数字、`（）「」〔〕、` | 原样保留（括号不保证配对，不要修正） |
| 单名超 240 字节 | 截断加 `…`，并写 `NAME_TRUNCATED` 警告 |

## 父项补零

同一册里，若某个序号既有父项、又有子项（`X.1`、`X.2`…），父项要写成 `X.0`，
与旧库的 `3.0.0` / `1.0独国` 保持同一体例：

| 同册条目 | 生成结果 |
| --- | --- |
| `2.出兵問題ニ関スル在外帝国使臣ノ意見等（…）` | `2.0出兵問題ニ関スル…` |
| `2.1…／１）在露` | `2.1…／１）在露` |
| `2.2…／２）在西 阪田公使` | `2.2…／２）在西 阪田公使` |

判断依据是"整册上下文"，单条看不出来，所以 plan 会先算全册再统一补零。

**例外**：`0.` 是无序号条目的占位（`0.表紙`、`0.1目次`、`0.2〔中表紙〕`），
即使同册存在 `0.1`、`0.2` 也不补零，否则会变成 `0.0表紙`。

## 全巻一册（扁平存放）

有些簿冊整册只有一份文件，JACAR 把它的「件名」直接著录成册名（如
`露国革命一件／帝国ノ態度 第四巻`）。此时不再套一层子目录：

```
帝国ノ態度/第四巻/
├── 露国革命一件／帝国ノ態度 第四巻.pdf
├── 目錄.md
└── 選擇材料.csv
```

判断依据：件名标题与簿冊标题经 `variant_key()`（异体字归一 + 去空格）比较后相同。

注意：这种条目的幂等检查只看**本层**（`dir_refcodes(..., recursive=False)`），
不能递归，否则会把子目录里别的条目的 refcode 误算进来。

## 目录名与 PDF 名分开

两者规则不同，这是刻意设计：

| | 用什么 | 目的 |
| --- | --- | --- |
| 文件夹 | 序号 + 正文（`1.1本邦／１ …`） | 保证 `1.1 → 1.2 → 2.1` 的阅读顺序 |
| PDF 文件 | **只取正文**（`本邦／１ 大正７年….pdf`） | 与 JACAR 页面逐字对照，便于引用 |

对照表：

| JACAR 标题原文 | 文件夹 | PDF |
| --- | --- | --- |
| `１．本邦／１ 大正７年２月１０日から大正１１年１１月８日` | `1.1本邦／１ 大正７年…` | `本邦／１ 大正７年２月１０日から大正１１年１１月８日.pdf` |
| `１４ 大正９年５月１３日から…` | `14.大正９年５月１３日から…` | `大正９年５月１３日から….pdf` |
| `表紙` | `0.表紙` | `表紙.pdf` |
| `３ 〔大正７年４月２日〕から〔大正７年４月１９日〕 １` | `3.1〔大正７年４月２日〕から… 1` | `〔大正７年４月２日〕から〔大正７年４月１９日〕 1.pdf` |

要点：

- PDF 名 = `derive_numbering()` 返回的 `rest`，**不经过 profile 的 `map`**（map 里存的是带序号的文件夹全名）
- 每个条目目录内只有一个 PDF，跨目录同名不冲突
- 标题只有序号没有正文时，回退 `{refcode}.pdf`
- 想改回「与文件夹同名」，用 `--pdf-name dir`

## 回归基线（2026-11-27，132 条可比）

```
L0  109 条  82.6%   完全一致
L1   18 条  13.6%   仅全角数字前缀不同（參考調書 第一卷 早期手工命名）
L2    5 条   3.8%   仅空格不同（历史遗留）
DIFF   0 条   0.0%
```

**不设一致率阈值。** L1/L2 是旧库历史写法，不必也不应强行对齐。

新册出现规则推不出的命名时，不要改全局规则，写 `references/profiles/{fond}.json`：

```json
{
  "fond": "B030511xxxxx",
  "numbering": "append",
  "tail_rule": false,
  "map": { "B030511xxxxx": "完整目录名" }
}
```
